THE SHORT VERSION

Rearrange the route. Measure the difference.

What we tried: compare established methods on synthetic maps, choose one using exploration results, then test it on 40 held-out maps of 48 places.

What happened: greedy 2-opt, which reverses a section of a route, gave routes 8.33% shorter on average than greedy swaps, which exchanges two stops. Both had the same limit on full route evaluations. “Held-out” means these maps were set aside from method selection.

What it means: a measured improvement over that baseline in this test. These are simulated maps, not live deliveries. This is an established algorithm, not a new invention or autonomous scientific discovery. Equal evaluation counts do not establish faster running time.

What’s next: fresh maps, other sizes, stronger baselines and timing tests. These remain recommendations.

01 / THE METHOD

Three roles. Executable checks.

INVESTIGATOR

A fixed catalog of development-time, AI-assisted hypotheses: reverse tour segments, relocate one city, or use simulated annealing. Each predicts at least a 1% mean reduction.

SKEPTIC

A rule-based gate rejects unmeasurable predictions, holdout leakage and unequal evaluation budgets. Written controls expose confounding factors and limits.

EXPERIMENTER

Standard-library Python executes the comparisons, verifies returned tours, records failures and selects one method before held-out testing.

These are deterministic stages, not independently running language-model agents. No APIs, keys, accounts or network connection are needed to reproduce the experiment.

02 / THE CHALLENGE

A shorter route through 48 cities.

The closed Euclidean travelling-salesperson problem has a clear objective: visit every city once, return to the start, and minimise total distance. Its combinatorial search space makes a useful offline test with several meaningful strategies.

All methods start from the same nearest-neighbor tour and receive 2,000 full tour-score evaluations, including the initial score. The baseline accepts improving city swaps. Candidates use segment reversal (2-opt), single-city relocation, or annealed segment reversal. Preprocessing is shared; equal evaluation counts do not imply equal running time.

We fixed 20 exploratory instance seeds, 40 separate validation seeds, three search seeds per instance and all parameters before execution. Selection uses the largest exploratory mean paired reduction, subject to a 1% threshold. Validation requires at least a 1% mean reduction, a positive lower 95% bootstrap bound and no failed runs. The bootstrap resamples whole instances, not repeated search runs.

Greedy 2-opt was frozen as the selected candidate before validation. On 40 held-out instances it achieved 8.332% mean reduction (instance SD 3.619%; 95% interval 7.282%–9.493%). It met the predefined success criterion. No other candidate was evaluated on the holdout.

Illustrative observed tours: the first predefined held-out instance (seed 1000), first search seed (7). This single pair was chosen by order, not performance; the statistical result uses all 40 instances.

04 / CAREFUL CONCLUSIONS

An improvement. A bounded claim.

This demonstrates a reproducible advantage over one legitimate local-search baseline under a fixed evaluation budget. 2-opt is an established heuristic. This is not a new scientific discovery or evidence of general autonomous discovery capability.

The strongest limitations: one synthetic distribution, one size and budget, no known optimality gaps, approximate bootstrap uncertainty, and no comparison with state-of-the-art solvers. Equal score counts are not equal CPU budgets. The public holdout is reproducible but not independently blinded, and must not be reused for later confirmatory claims.

Next recommended experiment

Externally register fresh seeds, add clustered instances and several city counts, compare against best-improvement 2-opt, and measure both evaluation and wall-time budgets. Include exact optima for small cases. Freeze the methods and analysis before execution.
